# Master-thesis
## Explainable AI in Clinical Genomics: A Holistic Framework for Transparent and Stable Decision-Making
### Applied to Clinical Genomics

## 📌 Overview
This repository contains the implementation of my Master’s thesis, which proposes a **domain-agnostic Explainable AI (XAI) framework** designed to improve transparency, interpretability, and stability of machine learning models.

The framework is applicable across multiple industries (healthcare, finance, energy, risk analytics) and is **validated using clinical genomics data** as a real-world, high-stakes application.

---

## 🎯 Problem Statement
Many machine learning models achieve high accuracy but lack interpretability and stability in their explanations, limiting trust and adoption in decision-critical domains.

This project addresses this challenge by combining predictive modeling with explainability and Feature Stability Index (FSI).

---

## 🧠 Methodology
- Data preprocessing and exploratory analysis  
- Feature engineering  
- Model training and evaluation  
- Explainability using SHAP, LIME, Permutation importance.
- Stability analysis of feature importance  

---

## 🤖 Models & Explainability
**Baseline Models**
- Logistic Regression  
- Decision Trees  
**Ensemble & Advanced Models**
- Random Forest  
- XGBoost 

**Explainability Techniques**
- SHAP  
- LIME
- Permutation importance

**Feature Stability Analysis**
- Cross-model feature importance comparison  
- Stability assessment across explainability methods  
---

## 📈 Key Results
- Achieved reliable classification performance  
- Identified domain-relevant features using explainability methods  
- Observed higher explanation stability with SHAP compared to local methods  

---

## 🧠 Key Contributions
- Proposes a **reusable, domain-independent XAI framework**
- Demonstrates explainability stability as a critical evaluation dimension
- Supports trustworthy AI adoption in real-world decision-making systems
